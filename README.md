# NMSU Studyroom Rating App

An app for NMSU students to discover and rate study spaces around campus.

## Getting Started

### 1. Clone the repository

Open a terminal and clone

### 2. Install dependencies

Make sure you have [Node.js](https://nodejs.org/) installed, then run:

```bash
npm install
```

### 3. Start the app

```bash
npx expo start
```

A QR code will appear in the terminal. Scan it with Expo Go on your phone to open the app.

**Note:** If you're using Windows PowerShell, use `npm.cmd install` and `npx.cmd expo start` if PowerShell blocks the regular commands.

## Notes

- If you can't clone the repository, make sure you have access to it on GitHub.
- After pulling new changes, run `npm install` if dependencies have changed.

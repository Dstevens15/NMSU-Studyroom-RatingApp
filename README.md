# NMSU Study Finder – Studyroom Rating App

## About the Project

NMSU Study Finder is a mobile application designed to help New Mexico State University students discover and evaluate study spaces around campus. Students can explore locations, read reviews, rate study environments, and share recommendations with other students.

## Key Features

- Browse study locations around NMSU.
- Rate and review study spaces.
- Save favorite locations.
- Recommend new study spaces.
- Explore campus amenities and food options.
- User accounts and administrator moderation.

## Technologies Used

- **Frontend:** React Native, Expo, TypeScript
- **Backend:** Node.js, Express.js
- **Database:** TiDB Cloud (MySQL-compatible)
- **Hosting:** Render

## Getting Started

To run the application locally:

```bash
git clone git@github.com:Dstevens15/NMSU-Studyroom-RatingApp.git
cd NMSU-Studyroom-RatingApp
npm ci
npx expo start
```

Open the project using Expo Go or an Android/iOS development build.

The application uses a hosted backend and database, so a separate backend installation is not required for normal use.
